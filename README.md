### 🚀 Featured Data Science Project

[![Kenya Household Electric Power Telemetry Banner](https://raw.githubusercontent.com/steph45acke-hue/KENYA_HOUSEHOLD_ELECTRIC_POWER_CONSUMPTION/main/bunner.png)](https://github.com/steph45acke-hue/KENYA_HOUSEHOLD_ELECTRIC_POWER_CONSUMPTION)

#### **[Kenya Household Electric Power Telemetry](https://github.com/steph45acke-hue/KENYA_HOUSEHOLD_ELECTRIC_POWER_CONSUMPTION)**
An end-to-end data engineering, relational SQL warehousing, and machine learning forecasting project analyzing household power telemetry (`kW` / `kWh`), load profiles, high-load events, and anomalies across chronological time splits.
- **ETL, SQL Warehousing & Optimization**: Built idempotent ingestion/ETL pipelines, relational/star-schema SQL tables, composite indexing benchmarks, atomic transaction rollbacks, and SQL-to-Pandas daily energy reconciliation.
- **Feature Engineering & Leakage Prevention**: Engineered strictly past-available lag, rolling window, cyclical calendar, sub-meter share, and residual energy features under a chronological train/validation/test split fitted on training folds only.
- **Forecasting, Classification, Clustering & Diagnostics**: Benchmarked linear and tree-ensemble regressors (`RandomForest`, `ExtraTrees`, `GradBoost`) and high-load classifiers (`>= 2.5 kW` at `t + 1h`), paired with daily load-profile clustering, anomaly detection, prediction intervals, and hourly error/explainability analysis.

[![Kenya Economic Intelligence & Forecasting Engine Banner](https://raw.githubusercontent.com/steph45acke-hue/KENYA_ECONOMIC_INTELLIGENCE_AND_FORECASTING_ENGINE/main/bunner.png)](https://github.com/steph45acke-hue/KENYA_ECONOMIC_INTELLIGENCE_AND_FORECASTING_ENGINE)

#### **[Kenya Economic Intelligence & Forecasting Engine](https://github.com/steph45acke-hue/KENYA_ECONOMIC_INTELLIGENCE_AND_FORECASTING_ENGINE)**
An interactive, cloud-deployed macroeconomic forecasting platform engineered to predict retail maize prices in Kenya by modeling macro dynamics (CPI, exchange rates, central bank interest rates) alongside historical price signals.
- **Database & Pipeline Architecture**: Built with a normalized MySQL database schema (`kenya_economic_db`) managed via SQLAlchemy and optimized Pandas/NumPy ETL pipelines with anti-leakage temporal feature engineering.
- **Machine Learning & Econometric Modeling**: Implemented baseline Linear Regression, L2-regularized Ridge models, and Tuned Random Forest Regressors to capture non-linear market interactions across out-of-sample evaluation windows.
- **Interactive Cloud Web Application**: Deployed live on Streamlit Community Cloud, featuring dynamic model evaluation tabs, residual error diagnostics, feature importance weightings, and real-time scenario simulation controls.


[![Kenya Agricultural Market Intelligence & Forecasting Engine Banner](https://raw.githubusercontent.com/steph45acke-hue/KENYA_AGRICULTURAL_YIELD_AND_MAIZE_PRICE_FORECASTING_ENGINE/main/banner.png)](https://github.com/steph45acke-hue/KENYA_AGRICULTURAL_YIELD_AND_MAIZE_PRICE_FORECASTING_ENGINE)

#### **[Kenya Agricultural Market Intelligence & Forecasting Engine](https://github.com/steph45acke-hue/KENYA_AGRICULTURAL_YIELD_AND_MAIZE_PRICE_FORECASTING_ENGINE)**
An interactive, production-grade decision support platform engineered to monitor wholesale maize prices, track county supply chains, analyze rainfall impact on crop yields, and generate 6-month econometric price predictions across key Kenyan agricultural hubs.
- **Geospatial & Database Engineering:** Built using MapLibre mapping and a normalized relational database schema structured in MySQL Workbench, featuring optimized multi-table querying and spatial data pipelines.
- **Data Analytics & Time-Series Modeling:** Powered by Python, Pandas (v3.0+), and NumPy, performing comparative trend analysis, weather-yield correlation metrics, and robust temporal feature engineering.
- **Econometric Forecasting & Interactive Frontend:** Deployed via an executive Streamlit web application featuring 6-month predictive pricing models, 95% uncertainty confidence intervals, and dynamic agricultural market intelligence dashboards.
